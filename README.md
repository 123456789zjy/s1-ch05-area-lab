# S1 5.1 面積實驗室

適合在 iPad Safari 投影使用的中一數學互動網頁，配合 Chapter 5.1 的面積教學。

## 課堂內容

- 透過可播放、可拖動的圖形推導正方形、長方形、平行四邊形、三角形和梯形的面積公式。
- 用觸控筆或手指畫分割線，探索多邊形切割法。
- 拖動填補進度，對比「分開再加」和「補上再減」。
- 先讓學生估計和討論，再顯示算式與答案。
- 可切換中文、英文或中英對照；圖形可旋轉及縮放。
- 六個複合圖形例題，包括可橫切／直切的兩種 L 形、屋形、梯形屋頂、T 形及需要兩條線的 U 形。
- 旋轉或縮放後仍可用手指畫切割線；亦可按「顯示切法」作課堂示範。

## 使用方式

直接開啟 `index.html`，或透過 GitHub Pages 的公開網址使用。網頁由 `index.html` 和 `app.js` 組成，不需登入、安裝或連接第三方服務。教學例子的尺寸是獨立示例，工作紙上的數值仍以學校教材為準。

建議在 iPad Safari 加入主畫面，方便課堂快速開啟。首次載入後，只要頁面未被關閉，即使網絡短暫中斷，已載入的互動仍可繼續使用。
