# S1 5.1 面積實驗室

適合在 iPad Safari 投影使用的中一數學互動網頁，配合 Chapter 5.1 的面積教學。

## 課堂內容

- 透過可播放、可拖動的圖形推導正方形、長方形、平行四邊形、三角形和梯形的面積公式。
- 用觸控筆或手指畫分割線，探索多邊形切割法。
- 拖動填補進度，對比「分開再加」和「補上再減」。
- 先讓學生估計和討論，再顯示算式與答案。

## 使用方式

直接開啟 `index.html`，或透過 GitHub Pages 的公開網址使用。網頁只有一個 HTML 檔案，不需登入、安裝或連接第三方服務。教學例子的尺寸是獨立示例，工作紙上的數值仍以學校教材為準。

建議在 iPad Safari 加入主畫面，方便課堂快速開啟。首次載入後，只要頁面未被關閉，即使網絡短暫中斷，已載入的互動仍可繼續使用。
